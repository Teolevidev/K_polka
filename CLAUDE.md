# CLAUDE.md - Книжная полка (K_polka)

## Что это
Веб-приложение: закрытый книжный клуб + трекер прочитанных книг.
Владелец - Teo. На старте - клуб для 10-15 знакомых коллег (онлайн, но
все в одном офисе, возможны живые встречи). В перспективе freemium:
открытая часть для всех, закрытый функционал за подписку.

## Текущий статус
- Фаза 1 (фундамент) готова: каркас, главная, поиск книг
  (Google Books + OpenLibrary, fuzzy), страницы книг, темы, i18n RU/EN,
  схема БД, авторизация.
- Фаза 2 (в работе): полки, статистика чтения, цели, отзывы и рейтинги,
  профили.
- Фаза 3 (позже): платежи (YooKassa).

## Стек
- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS 3, дизайн-система на CSS-переменных, шрифты Inter + Lora
- Supabase (Postgres) + Drizzle ORM
- Supabase Auth (magic link + Google/Apple OAuth)
- next-intl (RU/EN)
- Хостинг: Vercel + Supabase, пакетный менеджер pnpm
- Источник истины по схеме БД - supabase/migrations

## Команды
pnpm dev / build / test / typecheck / lint / db:push

## Как работать в этом репозитории
- Перед изменениями читай docs/design.md.
- Изменения - в отдельной ветке, осмысленные коммиты, при готовности PR.
- После правок гоняй pnpm typecheck и pnpm test, держи тесты зелёными.
- Остаёмся на Vercel + Supabase, без vendor lock-in.

## Стратегические решения (штаб - в отдельном чате со стратегом)
- Сначала валидация: опрос среди первого круга до тяжёлой стройки Фазы 2.
- Первый круг - основатели, статус навсегда; монетизируем позже новую
  аудиторию.
- Граница free/paid: открытое - витрина и рекомендации; закрытое -
  обсуждения, сообщество, кураторские подборки, встречи.
- Геймификация мягкая: без наказывающих серий и рейтингов
  «кто больше прочитал»; прогресс личный.
- Обсуждения асинхронные по умолчанию, живое - по желанию.
