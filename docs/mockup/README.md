# Макет интерфейса

Исходники макета «Книжной полки»: семь экранов на одном холсте.

Живой макет: https://claude.ai/code/artifact/302bb64c-93c8-4c32-b6cf-e54445882a5b

## Что здесь

| Файл | Экран |
|---|---|
| `Main.dc.html` | Лендинг: герой, коллаж обложек, сетка возможностей, цитата, отзывы |
| `Library.dc.html` | Моя полка: табы статусов, сетка книг, свои полки |
| `Book.dc.html` | Страница книги: обложка, метаданные, прогресс, цитаты, отзывы |
| `Quotes.dc.html` | Лента цитат клуба |
| `QuoteAdd.dc.html` | Новая цитата, десктоп: выбор способа и вставка текста |
| `QuotePhone.dc.html` | Новая цитата, телефон: снимок страницы и распознанный текст |
| `Profile.dc.html` | Профиль: показатели, цель года, достижения, выписки |
| `canvas.json` | Раскладка экранов на холсте, заметки |

## Откуда взяты стили

Не из головы и не из чужого референса: цвета, шрифты, радиусы и размеры
сняты из реального кода проекта.

- Палитра - `src/app/globals.css` (терракота `#96412C`, фон `#FCFAF8`,
  рамки `#E2DDD5`, золотой акцент `#CC9933`)
- Шрифты - Inter для интерфейса, Lora для заголовков
- Радиусы - 10px у карточек, 8px у кнопок (`--radius: 0.625rem`)
- Кнопки - высота 40px, `h-10 px-4`, из `src/components/ui/button.tsx`
- Карточки - рамка плюс мягкая тень, из `src/components/ui/card.tsx`
- Шапка - 64px, липкая, из `src/components/layout/header.tsx`

Структура экранов взята как референс у literal.club - см.
`docs/reference/literal-analysis.md`. Дизайн при этом свой.

## Как пересобрать

Макет собирается из этих файлов в один HTML-холст. Каждый `.dc.html` -
отдельный артборд, `canvas.json` задает раскладку. Пересборка идет
через инструмент Claude Code (навык `design`), файлы отсюда - источник
истины для нее.

## Оговорки

- Отзывы на лендинге - намеренные заглушки `[ИМЯ УЧАСТНИКА]`. Клуб еще
  не запущен, реальные цитаты подставим после опроса.
- Книги, цитаты и показатели - демонстрационные данные, чтобы верстка
  проверялась на живой длине строк.
- Цвета на каждом экране вынесены в чипы сверху, но между экранами не
  синхронизируются. Сквозная смена палитры - пересборкой всех файлов.
