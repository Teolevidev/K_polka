# Иллюстрации

Сюда кладутся фирменные иллюстрации. Файлы отсюда раздаются по путям
вида `/illustrations/<имя>` - без префикса `public`.

## reader.png

Девушка с телефоном на стопке книг. Используется в двух местах:

- крупно над каруселью на главной (`src/app/page.tsx`);
- повторяющимся паттерном на фоне всех зеленых лент
  (`src/components/layout/section-band.tsx`).

Прозрачность паттерна задается одной переменной `--pattern-opacity`
в `src/app/globals.css`.

Формат: PNG с прозрачным фоном (или SVG - тогда поменяйте расширение в
`ILLUSTRATION` в `src/components/layout/illustration.tsx`). Пока файла
нет, оба места просто ничего не рисуют - разметка не ломается.
