# Иллюстрации

Сюда кладутся фирменные иллюстрации. Файлы отсюда раздаются по путям
вида `/illustrations/<имя>` - без префикса `public`.

## reader.png

Девушка с телефоном на стопке книг. Используется в двух местах:

- крупно над каруселью на главной (`src/app/page.tsx`);
- повторяющимся паттерном на фоне всех зеленых лент
  (`src/components/layout/section-band.tsx`).

Прозрачность паттерна задается одной переменной `--pattern-opacity`
в `src/app/globals.css`.

Формат: PNG с прозрачным фоном, 1799x1285. Извлечен без потерь из PDF,
присланного заказчиком: внутри лежал FlateDecode (обычный zlib, не
JPEG), поэтому пиксели ровно те же, что были в исходном webp. Альфа-
канал приехал отдельным потоком SMask и приклеен обратно - без него фон
стал бы черным.

Раздается через `next/image`: исходник вдвое шире, чем слот на странице,
и без пережатия страница тянула бы лишние сотни килобайт. Размеры
прописаны в `src/components/layout/illustration.tsx` - если замените
файл на другой, поправьте там WIDTH и HEIGHT, иначе место под картинку
будет резервироваться неправильно.

Если файла нет, оба места показывают запасной вариант, а не иконку
битой картинки.
